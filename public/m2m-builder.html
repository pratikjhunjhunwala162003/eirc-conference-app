👥 Dais Pool — Common Persons List
Add people who frequently appear on the dais. In "Calling to Dais" rows, pick names from this list. Upload from Excel or add manually.
📅 Event Days
For a seminar spanning more than one day. Add a day for each date, then set the Day on every session. Each day starts its own timing chain, so Day 2 begins fresh rather than carrying on from where Day 1 finished. Leave this empty for a single-day event.
🏫 Parallel Sessions — Breakout Halls / Class Rooms
Sessions that run at the same time as the main programme, in a separate hall or class room. Each hall holds its own list of sessions, built exactly like the main hall — time slots, dais, speakers, panel discussions and all row types.
